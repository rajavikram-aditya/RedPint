# Blood Connect

need a full website ui for my RedPint is a full-stack web application that solves a real problem in emergency healthcare: hospitals struggling to find compatible blood donors quickly. Donors register with their blood group, location, and donation history, while hospitals post urgent blood requests specifying group, units, and urgency. An automated matching engine filters donors by blood-type compatibility, geographic proximity, and eligibility, using a fixed 90-day donation cooldown. Matched donors receive real-time notifications and can accept or decline. On acceptance, hospitals gain access to donor contact details for direct coordination. The platform also supports inter-hospital stock visibility, blood donation drives, and self-reported inventory, moving beyond static donor directories toward genuine hospital-network coordination.
